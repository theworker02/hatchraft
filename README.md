# hatchraft

Hatch config/raft key checks for twelve-factor services.

**Site:** https://theworker02.github.io/hatchraft/

## Install / run

```bash
git clone https://github.com/theworker02/hatchraft.git
cd hatchraft
node src/cli.js
node --test
```
